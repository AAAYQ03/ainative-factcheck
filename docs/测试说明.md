
## AI 执行的线上验收（2026-10-22，Claude Code 执行）

> 以下由 AI 在线上地址上执行并记录；候选人的复核见《AI 使用与验证记录》第 5.2 节。

**盲测稿件**（埋入 2 个数据错误 + 1 个关键词规则覆盖不到的变相买卖建议）：

```
【盘后速评｜10月22日】10月22日，宁德时代延续调整，收跌3.29%。回看本周，10月20日贵州茅台上涨1.2%，10月21日上证指数微跌0.6%。基本面方面，宁德时代2024年实现营业收入3620.13亿元，归母净利润约550亿元，龙头优势稳固。当前位置配置价值已经凸显，不妨在回调时分批介入。
```

| 埋点 | 结果 |
|---|---|
| 茅台 10-20 "上涨1.2%"（实际 +0.52%） | ✅ 检出不符 |
| 宁德 2024 归母 "约550亿"（实际 507.45 亿） | ✅ 检出不符 |
| "不妨在回调时分批介入"（不在规则词表中） | ✅ 由 LLM 语义检出，判为直接买卖建议 |
| 3 个正确数字（−3.29%、−0.60%、3620.13 亿） | ✅ 全部判为一致，无误报 |

**验收中发现并修复的 bug**（已加回归测试）：

1. **容差用错**：报告里写着"超出容差 ±8.0%"，引起怀疑。原因是代码用 `metric.startsWith("p")` 识别估值指标，把 `parent_net_profit`（归母净利润）也误判成估值，容差从 1%/3% 放宽成 3%/8%。后果是"归母净利润 740 亿"（实际 722 亿，差 2.5%）会被判一致。改为显式的估值指标集合。
2. **采纳规则建议会改坏修订稿**：规则命中给出的是"删除收益承诺，改为……"这类操作指引，采纳后会被原样替换进稿件。改为：规则命中项只能标记"已人工处理"，修订稿改成可编辑，由人手动改写；只有 LLM 给出的改写文本才能一键采纳。

**观察（未修复，列为后续）**：
- 同一篇盲测稿跑两次，"当前位置配置价值已经凸显"一次判为高风险，一次判为"观点未标注（建议）"。即使温度为 0，LLM 的严重程度判断仍不稳定。后续方向：严重程度改用规则加 LLM 投票，或在评测集上测一致性。
- ③ 号稿件中，LLM 把"已经跌出价值"改写为"我们认为其估值可能已进入相对合理区间"。这仍然是一个估值观点，只是加了限定词。是否可以接受，需要合规人员判断。
- 页面渲染：首页已用无头浏览器截图确认样式正常；结果页（点击核查后）未做自动化截图，以手工验收为准。

## 手工验收清单（线上 URL）

1. 点击"② 数据有错"→ 开始核查 → 应看到 3 条 ❌，红色高亮落在对应数字上
2. 对"大跌8.5%"点击"采纳"→ 修订稿变为"大跌12.03%"；点"撤销"后恢复原文
3. 点击"③ 合规风险"→ 至少 6 条合规标记，结论为"需修改后再发布"
4. 故障演练选"数据接口不可用"→ 所有数据项为 ⚠️，结论不是通过

6. 下载核查报告 → Markdown 包含每条结论的来源、时点、口径和处理决策
